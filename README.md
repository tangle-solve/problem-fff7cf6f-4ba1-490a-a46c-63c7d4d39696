### ALGO-000149: Optimal output-sensitive high-dimensional convex hulls
- **Subfield:** Computational geometry
- **Open:** For fixed dimension, compute a convex hull with \(f\) output facets in \(O(n\log f+f)\) time.
- **Status:** Optimal bounds are known in low dimensions; higher-dimensional output sensitivity retains gaps.
- **Type:** theory
- **Why:** Avoids paying worst-case hull complexity when the actual output is small.
- **Key works:** Chan (1996), *Output-Sensitive Results on Convex Hulls, Extreme Points, and Related Problems*; TOPP Problem 15.
- **Related:** Polyhedral geometry—face complexity; optimization—explicit polytope construction.
